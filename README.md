## Planned gameplay features

Like in any traditional Snake games, player takes a control of a snake in either sealed or border-connected level of rectangle shape. Using directions UP, DOWN, LEFT and RIGHT player controls Snakes movement.

Gathering food increaces points. 

Special food is available for a limited time and provide extra points.

Colliding into Snakes body or borders, the Snake is crushed and dead. Try again!
